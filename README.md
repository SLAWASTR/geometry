# 🎯 Тригонометрический круг (Trigonometric Circle)

> **Автор:** `@slawastr 1-26 design`

Красивое, удобное и понятное приложение в стиле **macOS Liquid Glass** для решения школьных и университетских задач по тригонометрии с тригонометрическим кругом, пошаговыми объяснениями и поддержкой диапазона углов **$\pm 5000^\circ$**.

Адаптируется под любые экраны:
- **Desktop (macOS Split-View)**: полноценное окно macOS с кнопками управления («светофор»), двухколоночным интерфейсом, Liquid Glass размытием и интерактивным кругом.
- **Mobile (Android / iOS)**: эргономичный мобильный интерфейс, оптимизированный под сенсорное управление.

## ✨ Возможности и особенности

### 1. Ввод дробей как в учебнике
- **Тумблер режимов**:
  - **Строка (`/`)**: быстрый ввод выражений вида `3π/4`, `13π/6`, `-7π/4`, `-16п/3`.
  - **Дробь как в учебнике**: двухэтажный ввод с отдельным числителем, знаменателем и знаком $\pm$.
- **Умное распознавание числа Пи**:
  - Понимает символ `π`, а также русский ввод: `п`, `П`, `пи`, `Пи`, `ПИ`, и английский `pi`, `PI`.
- **Быстрые кнопки**: `π`, `/`, `±`, `°`, `+π`, `Сброс`, а также быстрый выбор знаменателей `/2`, `/3`, `/4`, `/6`.
- **Готовые примеры**: выбор популярных углов одним кликом (`3π/4`, `13π/6`, `5π/3`, `17π/6`, `-7π/4`, `-π/6`, `-11π/6`, `-16π/3`, `π`, `3π/2`).

### 2. Большой интерактивный тригонометрический круг
- Чёткие координатные оси $X (\cos)$ и $Y (\sin)$ со стрелками и центром $(0, 0)$.
- Основные засечки и подписи: **$0^\circ / 360^\circ$**, **$90^\circ$**, **$180^\circ$**, **$270^\circ$** и соответствующие радианы ($0 / 2\pi$, $\pi/2$, $\pi$, $3\pi/2$).
- Римские обозначения четвертей прямо на круге: **I**, **II**, **III**, **IV**.
- Промежуточные засечки для ключевых углов ($30^\circ$, $45^\circ$, $60^\circ$ и т.д.).
- **Цветная подсветка текущей четверти** или фиксация положения на оси.
- **Траектория вращения**:
  - В пределах одного оборота: гладкая дуга с направлением (синяя против часовой стрелки для $>0$, красная по часовой для $<0$).
  - При превышении $360^\circ$ (до $\pm 5000^\circ$): архимедова спираль с бейджем количества полных оборотов (например, `+2.5 об.` или `−4.2 об.`).
- Пунктирные проекции на оси косинуса и синуса с точными координатами.
- Контрастный оранжевый луч с яркой светящейся точкой на окружности.
- Интерактивное вращение луча мышью или касанием пальца с магнитным прилипанием к ключевым углам ($15^\circ, 30^\circ, 45^\circ$).

### 3. Исследование углов в диапазоне $\pm 5000^\circ$
- Ползунок с плавным ходом и мгновенным откликом.
- Кнопки быстрого шага: **`−360°`**, **`−90°`**, **`0°`**, **`+90°`**, **`+360°`**.

### 4. Ключевые метрики и функции
- **Исходный угол**: в градусах и радианах.
- **Угол на круге $[0^\circ, 360^\circ)$**: после отбрасывания или прибавления полных оборотов.
- **Положение на плоскости**: четверть (I, II, III, IV) или координатная полуось ($+Ox, +Oy, -Ox, -Oy$).
- **Ближайшая засечка**: расстояние в градусах до ближайшей из засечек ($90^\circ, 180^\circ, 270^\circ, 360^\circ$). При равенстве расстояний (как для $45^\circ$) отображаются обе засечки.
- **Точные тригонометрические значения**: $\sin, \cos, \operatorname{tg}, \operatorname{ctg}$ в виде точных дробей с корнями ($\frac{\sqrt{2}}{2}, \frac{\sqrt{3}}{2}, \dots$).

### 5. Пошаговое школьное решение простым языком
- **Шаг 1**: Подробный перевод из радиан в градусы с подстановкой $\pi = 180^\circ$ и сокращением дроби.
- **Шаг 2**: Анализ знака, направления вращения и исключение полных оборотов по формуле $\alpha_0 = \alpha \pm 360^\circ \cdot k$.
- **Шаг 3**: Определение координатной четверти с границами.
- **Шаг 4**: Сравнение расстояний до всех четырёх засечек и нахождение ближайшей.
- **Шаг 5**: Координаты точки $(\cos \alpha, \sin \alpha)$ и значения функций.
- **Кнопка «Скопировать»**: копирует весь ход решения в буфер обмена для вставки в домашнее задание или мессенджер.

## 🛠️ Сборка APK для Android

В проекте настроен автоматический CI/CD через GitHub Actions (`.github/workflows/build-apk.yml`).

При каждом коммите в ветку `main`:
1. Виртуальная машина Ubuntu запускает Gradle 8.2 с JDK 17.
2. Собирается автономный APK `TrigCircle.apk` на базе Android WebView.
3. Готовый файл автоматически прикрепляется к GitHub Releases и загружается в артефакты сборки.

Локальная сборка (при наличии Android SDK / Gradle):
```bash
cd android
./gradlew assembleDebug
```
