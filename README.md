# 🎯 Тригонометрический круг (Trigonometric Circle)

> **Автор:** `@slawastr 1-26 design`

Современное, красивое и наглядное приложение для изучения тригонометрии и решения задач с единичной тригонометрической окружностью. Доступно в двух версиях:
1. **Нативное приложение для macOS** (Swift / SwiftUI).
2. **Мобильное адаптивное веб-приложение / PWA** (Touch Canvas, iOS-стиль, поддержка любых смартфонов, планшетов и ПК).

---

## ✨ Возможности

- **Ввод углов как в учебнике**:
  - Тумблер переключения: **Строка (`/`)** или **Школьная дробь** с отдельными полями числителя и знаменателя, чертой дроби, знаком $\pm$, быстрой вставкой $+π$ и выбором знаменателей (`/2`, `/3`, `/4`, `/6`).
  - Распознавание буквы Пи в любом виде: `π`, `п`, `П`, `пи`, `Пи`, `ПИ`, `pi`, `Pi`, `PI`.
- **Расширенный диапазон градусов**:
  - Поддержка углов **от $-5000^\circ$ до $+5000^\circ$** в обеих версиях!
  - Быстрые шаги вращения: $\pm 360^\circ$ (целый оборот), $\pm 90^\circ$ (четверть), сброс на $0^\circ$.
- **Наглядный тригонометрический круг**:
  - Горизонтальная ($X, \cos$) и вертикальная ($Y, \sin$) оси со стрелками и центром $O(0, 0)$.
  - Ключевые засечки: $90^\circ$ ($\pi/2$), $180^\circ$ ($\pi$), $270^\circ$ ($3\pi/2$), $360^\circ$ ($2\pi$ / $0^\circ$).
  - Разметка стандартных углов ($30^\circ, 45^\circ, 60^\circ \dots$).
  - Конечный луч с точкой на окружности и пунктирными проекциями на оси.
  - Направление вращения: против часовой стрелки для положительных углов, по часовой стрелке для отрицательных.
  - Архимедова спираль для углов с несколькими оборотами (до $\pm 5000^\circ$) с бейджем числа оборотов.
  - Подсветка активной четверти (I, II, III, IV) или фиксация положения на оси.
  - Интерактивное управление: можно вращать луч пальцем или мышкой прямо по кругу.
- **Информационные карточки**:
  - Исходный угол в радианах и градусах.
  - Угол после приведения к $[0^\circ, 360^\circ)$ с указанием числа отброшенных/прибавленных оборотов.
  - Номер четверти или ось координат (угол на оси не относится к четверти).
  - Ближайшая ключевая засечка и угловое расстояние до неё (при равенстве расстояний указываются обе засечки).
- **Пошаговое школьное решение**:
  - Перевод из радиан в градусы с подробными промежуточными сокращениями.
  - Учёт знака и приведение к одному обороту.
  - Определение четверти по школьным интервалам.
  - Сравнение расстояний до всех ключевых засечек.
  - Точные табличные значения тригонометрических функций с корнями ($\sin, \cos, \operatorname{tg}, \operatorname{ctg}$).
  - Кнопка «Скопировать» для копирования всего решения в буфер обмена.

## 🚀 Запуск на macOS

1. Двойным кликом запустите `Тригонометрический Круг.app` или файл `Запустить_Приложение.command`.
2. Либо выполните в терминале:
   ```bash
   bash run.sh
   ```

---

## 📱 Мобильная версия

Мобильное приложение находится прямо в корне репозитория (`index.html`, `css/style.css`, `js/`).
- Для локального запуска:
  ```bash
  python3 -m http.server 8080
  ```
  и откройте `http://localhost:8080` на компьютере или смартфоне.
- Для публикации на **GitHub Pages**:
  В настройках репозитория `https://github.com/SLAWASTR/geometry` перейдите в **Settings → Pages** и выберите ветку `main` — мобильное приложение сразу станет доступно всему миру онлайн!
